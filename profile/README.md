# Vespertine

A free, open-source music player for Mac, built for hi-res and surround collections, with an iPhone app.

- SACD and DVD-Video disc images, DSD, DTS CDs, DTS-HD MA, TrueHD and Dolby Atmos files
- Spatial Audio on AirPods
- Room correction measured in your own room
- A bit-perfect signal path you can inspect
